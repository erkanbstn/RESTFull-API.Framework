# REST API

Kategori kayıtlarını sunan REST API.

## Ne var

Uçlar `KategorisController` ve `ValuesController` içindedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework Web API ve Entity Framework.
